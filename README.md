# WebSize

**Конвертер пикселей (px) в адаптивные единицы (vw/vh) для веб-разработчиков**

<p align="center">
  <img src="src/assets/icon.png" width="128" alt="WebSize Icon">
</p>

## 🚀 Возможности

- **4 типа устройств** — Мониторы (1920×1080), Планшеты (772×926), Телефоны (374×812) + возможность задать свои размеры
- **Двусторонняя конвертация** — PX → VW/VH и обратно
- **Закладки** — сохраняйте нужные значения с названиями, редактируйте и удаляйте
- **Копирование в буфер** — клик по результату — и CSS готов
- **Темная тема** — никакой боли для глаз

## 📖 Как пользоваться

1. Выберите устройство или введите свои ширину/высоту
2. Введите число в любое поле (PX, VW или VH)
3. Кликните по результату — значение скопируется в буфер
4. Сохраняйте нужные значения в закладки
